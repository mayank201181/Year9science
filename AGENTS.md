# Year 11 IGCSE Computer Science (`0478`) — Agent Notes

- Syllabus: **Cambridge IGCSE Computer Science (`0478` / `0984`)** — Paper 1 (*Computer Systems*) & Paper 2 (*Algorithms, Programming & Logic*), non-calculator.
- IEC storage units (`KiB`, `MiB`, `GiB`, `TiB`) ALWAYS use `1024` (`2^10`) on CIE `0478`; SI units (`kB`, `MB`, `GB`) use `1000`.
- CIE Pseudocode uses `←` for assignment, `<>` for not equal, `DIV` and `MOD`, 1-indexed `SUBSTRING(S, start, length)`, and `REPEAT ... UNTIL` stops when condition is `TRUE`.
